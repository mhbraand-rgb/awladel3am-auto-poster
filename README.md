# AwladEl3am Auto Poster

بوت احترافي لنقل منشورات تيليجرام تلقائيًا من قناة مصدر إلى قناة الهدف مع تعديل السعر وإضافة بيانات المكتب.

---

## المميزات

- مراقبة قناة المصدر لحظة بلحظة.
- نقل الصور.
- نقل الفيديوهات.
- نقل الألبومات.
- تعديل السعر تلقائيًا.
- إضافة بيانات المكتب.
- منع تكرار المنشورات.
- تسجيل جميع العمليات.
- قابل للتطوير.

---

## قواعد تعديل السعر

إذا كان سعر الجملة أقل من 400 جنيه:

السعر الجديد = السعر + 10 جنيه

إذا كان السعر 400 جنيه أو أكثر:

لا يتم تعديل السعر.
